# 大量アクセスと運用費用の対策

## 方針

- DB、Redis、利用者認証は追加しません。
- タイトル全体のレビューを1万件で打ち切りません。レビューを複数の区間に分割し、最後まで取得します。
- 通信が切れた場合、完了済みの区間と続きの取得位置だけをブラウザのメモリに保持します。再取得ボタンまたはCSVボタンで続きから再開します。
- ページをリロードすると、一時データと取得位置は消えます。
- CSVは全文取得の完了後にブラウザで生成します。AI分析用の全文キャッシュも、途中までの取得を全文として扱いません。

## サーバー側の上限

以下の上限は利用者単位ではなく、Node.jsプロセス単位です。IPヘッダーやCookieを変更しても、そのプロセス内の総量制限は回避できません。

| API | 10分間の受付数 | 同時実行数 | 1リクエストの時間上限 | 1レスポンスの送信上限 |
| --- | ---: | ---: | ---: | ---: |
| 通常分析 | 12 | 2 | 240秒 | 5MiB |
| 競合分析 | 4 | 1 | 240秒 | 2MiB |
| AI分析 | 12 | 2 | 170秒 | 2MiB |
| レビュー取得 | 60 | 1 | 150秒 | 20MiB |
| TOP候補取得 | 120 | 2 | 45秒 | 1MiB |

- 全API合計の同時実行数は4件です。
- APIレスポンスの合計送信量は256MiB/24時間/プロセスです。24時間はプロセス内での計測開始時を起点にします。
- 通常分析のリクエスト本文は4KiB、AI分析は512KiBまでです。Content-Length未指定の本文も実際の受信量で検査します。
- 通常分析は1回最大5タイトル、AIコーパスは最大16万文字です。
- 取得制限時はHTTP 429とRetry-Afterを返します。接続済みストリームの送信量超過時はストリームを中断します。
- 接続切断・キャンセル・時間超過時は、Steam/ITAD/Geminiへの処理をAbortSignalで中断します。
- エラーのたびにサーバーログへスタックトレースを出力しません。Gemini SDKの生エラーも画面には返しません。

## 大型タイトルの全文取得

- 1区間は最大100ページ（通常最大1万件）、レビューイベント16MiB、約100秒のいずれかで区切ります。処理中のページは完了させてから区切るため、100秒を多少超える場合があります。
- 続きのSteamカーソルを返し、ブラウザが次の区間を取得します。カーソルが進まない場合はエラーとして停止します。
- 送信量上限は完全なSteamページ単位で適用します。次の区間は、未送信ページの取得位置から始めます。
- 区間の完了通知が届かなかった場合、その区間は破棄します。以前の完了済み区間は保持します。再開時に重複するレビューIDは除去します。
- 自動取得は最大20分で一度中断します。「取得を中断」ボタンでも停止できます。再実行で完了済み区間の続きから取得できます。
- 5万件以上の場合のユーザー確認は維持します。
- 全文AIのタイムアウトは、レビュー取得が終わってGemini APIを呼ぶ段階から計測します。
- 旧サーバー直接CSV APIは410を返します。アプリ上のCSVボタンは新しい分割取得方式を使用します。
- 更新前から開いていたページには再読み込みを求めます。旧クライアントが最初の区間を全文と誤認しないため、分割対応リクエストには `chunked=1` を付けます。

## この対策で保証できないこと

- メモリだけの制限なので、プロセス再起動でリセットされます。複数インスタンスの制限値は合算され、同じ利用者の次のリクエストが別インスタンスに届く場合があります。
- 悪意あるユーザーが共有枠を消費すると、正常な利用者も429になります。利用者単位の公平性や、分散DDoS攻撃を完全に防ぐ仕組みではありません。
- Next.jsの静的ファイル配信、プラットフォームが生成するアクセスログ、Cloud Build、Artifact Registry、Cloud Storageは、このAPI送信量制限の計測対象外です。
- 時間超過で通信を中断しても、Gemini側ですでに処理された分の料金まで取り消せるわけではありません。AI料金はユーザー入力キー側に発生します。
- Google Cloud全体の請求額を固定する保証はありません。Cloud Runの利用額上限、予算通知、最大インスタンス数設定と併用してください。

## 検証

```powershell
npm.cmd run test:api-protection
npm.cmd run test:steam-reviews
npm.cmd run lint
npm.cmd run build
```

単体テストは外部のSteam/Gemini APIを呼ばず、25,050件の分割取得、送信量・頻度・同時実行制限、途中切断、429後の再開、取得済みキャッシュ再利用を確認します。
